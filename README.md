## Estàndards de treball

### Branques

Les branques de treball seguiran el format:

`canvi/nom-numero`

Exemples:

- `canvi/igor-01`
- `canvi/igor-02`
- `canvi/salim-01`
- `canvi/salim-02`
- `canvi/pol-01`
- `canvi/pol-02`

### Commits

Els missatges dels commits seguiran el format:

`feat: descripció del canvi`

### Pull Requests

Els Pull Requests es faran sempre des de la branca de treball cap a la branca `main`.

Cada Pull Request haurà de ser revisat per un altre membre de l'equip abans de fer la integració a `main`.
